O catálogo `countries.json` contém as 249 entradas ISO 3166-1 (países e
territórios) do pacote Debian `iso-codes`, com traduções pt_BR, mais `XK`
(Kosovo), usado por provedores GeoIP. Nenhuma consulta externa é necessária
para usar a interface. `code` é o valor persistido e `name` é o rótulo exibido.

Fonte: https://salsa.debian.org/iso-codes-team/iso-codes
